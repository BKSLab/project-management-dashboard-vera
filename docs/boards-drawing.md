# Редактор досок

`ProjectBoardPage` показывает вкладки проекта, `FreeBoardsPage` — личные доски. Выбранная доска хранится в `?board=<id>`. Обе страницы используют `BoardEditor`; API описан в [контракте досок](boards-contract.md).

## Управление

| Действие | Способ |
| --- | --- |
| Выделение, рамка | `V`, Shift добавляет объекты |
| Панорамирование | `H`, пробел или средняя/правая кнопка мыши |
| Прямоугольник, эллипс, ромб | `R`, `O`, `D` |
| Стрелка, линия, текст, стикер | `A`, `L`, `T`, `S` |
| Масштабирование у указателя | Колесо мыши / жест тачпада |
| Отмена / повтор | Ctrl/Cmd+Z, Ctrl/Cmd+Shift+Z или Ctrl+Y |
| Копирование / вставка / дублирование | Ctrl/Cmd+C, Ctrl/Cmd+V, Ctrl/Cmd+D |
| Поиск на доске | Ctrl/Cmd+F |
| Снять выделение / отменить жест | Esc |

Справка панели инструментов содержит полный список сочетаний. Двойной клик закрепляет инструмент для последовательного рисования. Shift сохраняет пропорции или угол; Alt временно отключает привязки. Фигура-контейнер перемещает полностью находящиеся внутри объекты; Ctrl/Cmd позволяет двигать только её.

Свойства выделения управляют стилем, текстом, соединителями и слоями. Панель «Инструменты» даёт выравнивание, равные интервалы, явные группы, блокировки, шаблоны и экспорт PNG/SVG. Дублируются выбранные объекты. Экспорт создаёт автономный файл без внешних картинок и CSS-переменных. Из личной доски можно создать проект.

## Устройство

Сцена — `Map` из объектов с устойчивыми локальными ключами. `IdRegistry` связывает ключи с серверными ID, поэтому отмена, повтор и правка копии работают и до ответа сервера. Один холст использует CSS transform для панорамирования и масштаба; объекты имеют общую шкалу слоёв.

Во время жеста `requestAnimationFrame` обновляет DOM. При завершении меняются сцена и история; `SaveQueue` собирает атомарный пакет и согласует назначенные ID. История включает стикеры, фигуры, группы, шаблоны и блокировки. Ненужные объекты вне видимой области не отрисовываются.

`remoteScene`, `sceneSignature` и `editorState` согласуют удалённые изменения со сценой и очередью. Перед переходом досылаются изменения; при возвращении на доску чтение ждёт незавершённого сохранения. Ошибка сохранения остаётся видимой; конфликт требует перечитать сцену. Общая ревизия защищает согласованность объектов и metadata.

`geometry`, `routing`, `anchors`, `snapping`, `group`, `layout` и `template` содержат расчёты без UI. Backend использует общий доменный пакет геометрии и batch также для операций агента/MCP. Текст и выделение доски не дают агенту дополнительных прав.

Оформление редактора находится в `frontend/src/components/board/board.css` и использует цвета, поверхности и радиусы личного проекта. Существующие светлые бумажные стикеры сохранены; произвольный выбранный цвет ограничивается по светлоте и насыщенности для читаемости. Масштаб и статус сохранения расположены выше плавающих кнопок чата.
