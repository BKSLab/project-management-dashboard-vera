# Задачи из заметки встречи

Превращает свободный текст в набор задач трекера — с подтверждением перед
записью.

Требуется MCP-токен трекера **с правом записи**.

## Шаги

1. Уточните проект, если он не назван: `list_projects`.
2. Вызовите `get_project`, чтобы знать названия стадий. Новые задачи по
   умолчанию попадают в первую стадию доски — этого обычно достаточно.
3. Прочитайте заметку и выделите **действия**, а не темы. Признак действия:
   есть глагол и понятно, что считать выполненным. «Обсудили авторизацию» —
   не задача. «Описать схему refresh-токена» — задача.
4. Для каждого действия соберите: заголовок, описание, исполнителя и срок —
   но **только если они явно есть в тексте**.
5. Перед созданием вызовите `search_tasks` по ключевым словам каждой задачи:
   похожая задача может уже существовать. Дубликаты в трекере вреднее, чем
   пропущенная задача.
6. **Покажите список того, что собираетесь создать**, вместе с отметками
   «похоже на существующую PROJ-N», и остановитесь.
7. После подтверждения создайте задачи через `create_task`.
8. Если в заметке есть договорённость по уже существующей задаче — не создавайте
   новую, а добавьте `add_comment` к ней.

## Правила

- Ничего не создавайте до подтверждения.
- Не додумывайте исполнителей и сроки. Нет в тексте — оставьте пустым, пусть
  заполнят в трекере. Придуманный срок хуже отсутствующего.
- Заголовок — до 80 символов, с глаголом в начале. В описание положите цитату
  из заметки, чтобы потом было видно происхождение задачи.
- Приоритет ставьте только при явных словах в тексте: «срочно», «блокер»,
  «до пятницы». Иначе не ставьте вовсе.
- Одна договорённость — одна задача. Не склеивайте несколько действий в одну
  задачу и не дробите одно действие на несколько.
- Если из заметки не выделяется ни одной задачи, так и скажите. Пустой список
  лучше выдуманного.

## Формат ответа

```
Из заметки выделено N задач.

1. Описать схему refresh-токена
   Исполнитель: Борис · Срок: 10.09 · Приоритет: HIGH
   Основание: «Борис до 10-го опишет схему refresh»
   ⚠️ Похоже на существующую PROJ-142

2. Согласовать макет профиля
   Исполнитель: не указан · Срок: не указан
   Основание: «нужно согласовать макет профиля»

Создать эти задачи?
```
