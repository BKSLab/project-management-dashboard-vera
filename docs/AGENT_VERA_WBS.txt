ФАЗА 3. РАЗРАБОТКА (Июнь Н3 — Август Н1) — Приоритетная фаза
================================================================

3.1 Разработка, юнит-тестирование, деплой RAG Server [Backend]

    Реализация:
    3.1.1 Препроцессинг документов: очистка, извлечение структуры (статьи/пункты, заголовки секций)
    3.1.2 Иерархический чанкинг: документ → секция → чанк (300–500 токенов, overlap 50–100)
    3.1.3 Генерация синтетических заголовков чанков и гипотетических вопросов (LLM на этапе ingestion)
    3.1.4 Эмбеддинг чанков и upsert векторов с метаданными в Qdrant
    3.1.5 Гибридный поиск: dense (cosine) + sparse (BM25) + RRF fusion
    3.1.6 Reranker: cross-encoder (BAAI/bge-reranker-base) над топ-20 кандидатами
    3.1.7 API: POST /search, POST /ingest, DELETE /document/{id}, GET /health

    Взаимодействие:
    3.1.8 Принимает HTTP-запросы от MCP Tools Server (POST /search) — синхронный hot path
    3.1.9 Хранит и читает векторы/метаданные в Qdrant (self-hosted)
    3.1.10 Экспортирует спаны embed_query / vector_search в Arize Phoenix через OTLP

    Тестирование:
    3.1.11 Юнит-тесты ingestion pipeline (чанкинг, заполнение метаданных)
    3.1.12 Юнит-тесты гибридного поиска и reranker на синтетических запросах

    Документация:
    3.1.13 Описание API-эндпоинтов и схемы метаданных чанков

    Деплой:
    3.1.14 Docker-образ RAG Service, деплой в тестовое окружение

3.2 Разработка, юнит-тестирование, деплой Agent Service [Backend]

    Реализация:
    3.2.1 Граф LangGraph: analyze_intent → call_kb_search → generate_with_context / generate_direct
    3.2.2 Системный промпт: роль, две аудитории, источники только из БЗ
    3.2.3 AgentState (TypedDict): session_id, user_id, messages, retrieved_chunks, tool_calls
    3.2.4 Стриминг токенов ответа по мере генерации

    Взаимодействие:
    3.2.5 Consumer очереди RabbitMQ agent.requests — приём задач от Next.js Proxy (асинхронный вход, retry x3 + dead-letter)
    3.2.6 HTTP-вызов MCP Tools Server (тул kb_search) через langchain-mcp-adapters — синхронный hot path внутри шага рассуждения LLM
    3.2.7 Чтение/запись состояния диалога в Redis (LangGraph checkpointer)
    3.2.8 SSE-стрим ответа клиенту по reply_to

    Тестирование:
    3.2.9 Юнит-тесты узлов графа и условных переходов (нужен тул / не нужен)
    3.2.10 Тесты восстановления состояния диалога из checkpointer

    Документация:
    3.2.11 Описание графа агента и системного промпта

    Деплой:
    3.2.12 Docker-образ Agent Service (worker), деплой в тестовое окружение

3.3 Разработка, юнит-тестирование, деплой MCP Server [Backend]

    Реализация:
