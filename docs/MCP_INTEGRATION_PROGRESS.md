## Итог

Все пять этапов плана закрыты. Ветка `feature/mcp-integration` готова к ревью и слиянию.

Открытые вопросы плана (раздел 10) остаются за владельцем:

1. ~~адрес и TLS~~ — решено: прямое подключение по `http://91.218.115.104:5173`, конфигурация собирается от origin страницы, nginx проксирует `/mcp`. TLS нет: токен ходит открытым текстом, см. примечание ниже;
2. срок жизни токена по умолчанию — реализовано 90 дней с выбором «без срока»;
3. ~~нужен ли `write`~~ — решения не требуется: реализованы оба скоупа, в форме по умолчанию `READ`.

**Про отсутствие TLS.** По HTTP токен передаётся в заголовке открытым текстом и виден на любом промежуточном узле. Для доступа из доверенной сети это приемлемо; при выносе в интернет нужен HTTPS, и тогда же стоит включить `session_cookie_secure=true`.
