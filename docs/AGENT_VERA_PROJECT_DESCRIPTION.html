О проекте

«Работа для всех» - платформа агрегации вакансий для людей с инвалидностью. Объединяет предложения с hh.ru и Работы России в едином интерфейсе, адаптированном под потребности соискателей с инвалидностью. Платформа уже работает в продакшне.

Агент Вера - AI-консультант, встроенный в платформу. Отвечает на вопросы соискателей с инвалидностью и работодателей о трудовых правах, квотах, льготах и защите при увольнении. База знаний строится на нормативных документах (ТК РФ, ФЗ-181 «О социальной защите инвалидов», подзаконных актах) и авторских статьях-систематизациях. Это уникальная ценность, которой нет ни на hh.ru, ни на Работе России.

Вера не заменяет юриста: она даёт первичную ориентацию - «какие у меня права», «что работодатель обязан сделать», «куда обратиться». Это доступный первый шаг, которого сейчас нигде нет в одном месте.

2

Проблема

Люди с инвалидностью сталкиваются с барьерами не только при поиске работы, но и при попытке разобраться в своих правах. Существующие платформы эту задачу не решают.

Для соискателей

Незнание прав при трудоустройстве: какие квоты существуют, какие льготы положены, как защититься от незаконного увольнения. Юридическая консультация дорогая и труднодоступна.

Для работодателей

Непонимание обязательств по квотам, доступных субсидий при найме и требований к оборудованию рабочего места для сотрудника с инвалидностью.

Информация разрозненна

Нормативные акты, разъяснения Роструда, судебная практика: всё в разных местах и написано сложным юридическим языком. Собрать и понять самостоятельно крайне сложно.

Платформы не консультируют

hh.ru и Работа России дают вакансии, но не объясняют права. Пользователь остаётся один на один с юридической неопределённостью.

4

Решение

Вера - диалоговый AI-консультант с базой знаний на основе нормативных документов и авторских материалов. Пользователь задаёт вопрос в свободной форме, Вера находит релевантные фрагменты из базы знаний и формирует понятный ответ с указанием источников.

Доступность

Доступна всем пользователям платформы без регистрации. Ответы появляются в реальном времени по мере генерации, без ожидания.

Точность источников

Ответы строятся только на проверенной базе знаний. Вера не придумывает: если информации нет, честно сообщает об этом и предлагает уточнить запрос.

Два контекста

Вера понимает с кем говорит (соискатель или работодатель) и адаптирует ответы под их контекст и потребности.

Конверсионная логика

Незарегистрированный пользователь получает базовую консультацию. При персональных запросах Вера органично предлагает войти в аккаунт.

5

Интеграция с платформой

Вера является частью «Работы для всех», а не отдельным продуктом. Она встроена в навигацию платформы и доступна с любой страницы.

Страница ассистента: раздел work-for-everyone.ru/assistant с интерфейсом чата и быстрыми кнопками-подсказками для старта разговора.
Навигация: ссылка на Веру присутствует в основном меню платформы наравне с поиском вакансий и избранным.
Единая авторизация: пользователь, вошедший в аккаунт на платформе, автоматически авторизован у Веры. Никакой отдельной регистрации.
Единый стиль: Вера использует дизайн-систему платформы. Пользователь не ощущает переход между продуктами.
Точка роста: в следующих итерациях Вера сможет работать с данными пользователя: показывать его избранные вакансии, искать по его городу, рекомендовать позиции прямо в диалоге.
6

Цели и задачи

Цель итерации 1: запустить базовую консультационную функциональность: Вера отвечает на вопросы о трудовых правах из базы знаний и доступна всем пользователям платформы без регистрации.

1
Наполнение базы знаний
Подготовка, очистка и индексация нормативных документов (ТК РФ, ФЗ-181, подзаконные акты) и авторских статей. Генерация синтетических заголовков и гипотетических вопросов для улучшения поиска по юридическим текстам.
2
Разработка RAG Service
Сервис семантического поиска: векторная база данных, модель эмбеддингов, гибридный поиск (семантика + ключевые слова), reranker для точного ранжирования результатов.
3
Разработка MCP Tools Server
Инструментальный слой агента: инструмент поиска по базе знаний kb_search, интеграция с RAG Service через HTTP.
4
Разработка Agent Service
Оркестратор диалога: управление контекстом сессии, принятие решений о вызове инструментов, формирование ответа через языковую модель, стриминг токенов в браузер.
5
Интеграция с платформой
Подключение чат-интерфейса к агенту, настройка стриминга, конверсионная логика для незарегистрированных пользователей, тестирование end-to-end сценариев.
6
Деплой и наблюдаемость
Развёртывание всех сервисов в Docker, настройка трассировки запросов, мониторинга качества ответов и ключевых метрик latency.
