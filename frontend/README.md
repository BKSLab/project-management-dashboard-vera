# Frontend Project Management Dashboard Vera

React-интерфейс персонального таск-трекера проекта «Агент Вера».

В модальном окне задачи доступны описание, срок, связанные документы, комментарии и файлы. Файлы можно выбрать, перетащить или вставить из буфера; изображения открываются в preview, остальные типы скачиваются.

## Стек

- React 19 и TypeScript;
- Vite;
- Tailwind CSS v4;
- TanStack Query для server state;
- Zustand для UI state;
- `@dnd-kit` для канбана;
- `react-aria-components` для доступных UI-примитивов.

## Запуск

```powershell
npm install
npm run dev
```

По умолчанию Vite использует `http://localhost:5173`, а backend должен быть доступен на `http://localhost:8000`. Frontend не требует `.env`; Docker-сборка обращается к API через относительный путь.

Все запросы отправляются на API с префиксом `/api/v1`.

## Основные экраны

- `/` — сводка проекта и шкалы «Пульса канбана»;
- `/kanban` — доска, поиск и модальное окно задачи;
- `/wbs` — интерактивная карта стадий и редактируемое дерево ИСР с rollup-прогрессом;
- `/docs` — поиск и управление документами;
- `/docs/:slug` — просмотр и редактирование Markdown-документа.
